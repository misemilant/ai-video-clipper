# AI Short Video Clipper

Aplikasi web AI Video Clipper untuk menganalisis dan membuat potongan video pendek secara otomatis.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Vercel

## Cara Menjalankan di Lokal

1. Extract file zip
2. Open terminal di folder `ai-clipper`
3. Install dependensi:
   ```bash
   npm install
   ```
4. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
5. Buka `http://localhost:3000` di browser Anda.
